# Максимальный Фиолетовый — каждый кадр референса

Исходник 3840×2160, 30 к/с, 725 кадров. Номер — по шкале 60 к/с (настоящие кадры на чётных номерах).
Описание: **камера · игрок · эффекты**; если строка пустая (″) — то же, что выше, меняются только замеры.

Замеры (автоматически, `tools/jnanim/refmetrics.py`, полные данные — `max_purple_metrics.csv`):
* **Ярк.** — средняя яркость кадра 0..1;
* **Синий / Красный** — самое крупное пятно цвета: центр `x,y` (0..1 от левого верхнего угла) и радиус `r` (доля высоты кадра);
* **Фиол. / Белое** — доля кадра, занятая фиолетовым / белым;
* **Кам.** — сдвиг картинки за кадр (доли кадра, + вправо/вниз) — по нему видно панорамы и тряску;
* в планах без эффектов цветные пятна не выводятся (это фон, другие игроки, интерфейс);
* **⟂** — жёсткая склейка/вставка/вспышка: промежуточный 60 к/с кадр перед ней **не сглаживается**, держится предыдущая картинка.

Промежуточные (нечётные) кадры 60 к/с в игре — плавная интерполяция между соседними чётными внутри одного плана; через ⟂ интерполяции нет, смысл кадров не меняется.
