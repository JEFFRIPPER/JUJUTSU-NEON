# JUJUTSU NEON — Русская версия

Мод для **Minecraft Forge 1.20.1**, построенный вокруг техник, перемещения и боевой системы в стиле Jujutsu.

## Что уже есть

- Повязка Годжо как активатор способностей.
- Шкала проклятой энергии.
- Переназначаемые клавиши через стандартные настройки Minecraft.
- Наземное и воздушное передвижение.
- Боковой и передний дэш.
- Заряжаемые прыжки.
- Сверхскорость.
- Дальний телепорт.
- Blue.
- Maximum Blue.
- Red.
- Maximum Red.
- Hollow Purple.
- Использование способностей в воздухе.
- Защита владельца от собственных разрушительных техник.
- 4K VFX для основных техник.
- 48 kHz stereo SFX.
- Оптимизированное разрушение блоков очередями, чтобы не убивать TPS одним тиком.

## Hollow Purple

- Каст: около 5 секунд.
- Дальность: 160 блоков.
- Первые 150 блоков — полный радиус.
- Последние 10 блоков — плавное затухание.
- Радиус тоннеля: 6 блоков.
- Урон: 200 сердец.
- Может уничтожать Bedrock.
- Не трогает критические технические блоки, которые могут сломать мир.
- После полёта остаётся фиолетовый остаточный VFX примерно на 5 секунд.

## 4K визуал

Основные техники используют нативные VFX 4096×4096:

- Blue
- Maximum Blue
- Red
- Maximum Red
- Hollow Purple

Тяжёлые PNG и аудио не хранятся напрямую в Git — они генерируются через `generate_resources.py`.

## Сборка

Нужно:

- Java 17
- Forge 1.20.1
- Gradle
- Python 3
- Pillow
- FFmpeg

Локальная сборка:

```bash
python3 -m pip install pillow
python3 generate_resources.py
gradle build
```

Готовый JAR появится в:

```text
build/libs/
```

## GitHub Actions

При пуше в `main` GitHub автоматически:

1. ставит Java 17;
2. устанавливает FFmpeg;
3. генерирует 4K VFX и аудио;
4. собирает Forge-мод;
5. загружает готовый JAR как Artifact.

## Управление

Основные бинды описаны в `JujutsuNeonMod.java` и могут переназначаться через стандартное меню управления Minecraft.
