# Анимации тела Jujutsu Neon

Свой движок (пакет `com.kira.jujutsuneon.anim`), устроенный по тем же принципам, что Epic Fight: поза
считается заново **в каждом кадре отрисовки** по реальному времени, ключи соединены плавными кривыми,
между анимациями — плавные переходы, кости собраны в иерархию (таз → корпус → голова и руки, ноги от таза).
Код и ресурсы Epic Fight не используются.

Из чего состоит:

| Файл | Что делает |
|---|---|
| `anim/Curve.java` | кривые ключей (плавные, без перехлёстов) |
| `anim/Clip.java`, `anim/ClipLoader.java` | анимация и её чтение из JSON (`jn_anim` и старый Player Animator) |
| `anim/Animator.java` | слои: действие, удар, отладка; вход, выход, смена анимации со сглаживанием |
| `anim/Locomotion.java` | движение: стойка, шаг, бег, сверхбег, присед, прыжок, приземление, дэши, зарядка, полёт |
| `anim/Rig.java` | иерархия костей, взгляд, ноги на землю, смешивание с ванильной позой |
| `BodyAnims.java` | связь с игрой: слой Player Animator, загрузка анимаций, запуск из кода |
| `BodyAnimNet.java` | запуск анимации с сервера для всех рядом |
| `BodyAnimCommands.java` | команда `/jnanim` |

Фиолетовый (`max_purple`) пока играет по-старому, через `MaximumPurpleAnimation`.

## Где лежат анимации

| Откуда | Путь | Когда подхватывается |
|---|---|---|
| Мод | `assets/jujutsu_neon/body_anims/*.json`, `assets/jujutsu_neon/player_animation/*.json` | при загрузке ресурсов (вход в мир, F3+T) |
| Папка игры | `config/jujutsu_neon/animations/*.json` | **сразу**: сохранили файл, через секунду новая версия в игре |

Имя анимации — имя файла без `.json`. Файл из папки с тем же именем заменяет встроенную анимацию,
так можно править анимации мода без пересборки.

## Кости и каналы

Кости: `body` (всё тело, вращается вокруг таза), `torso` (корпус), `head`, `rightArm`, `leftArm`,
`rightLeg`, `leftLeg`. Голова и руки крепятся к корпусу: наклонили корпус — плечи и шея едут за ним.

| Канал | Единицы | Что делает |
|---|---|---|
| `pitch`, `yaw`, `roll` | градусы | поворот кости |
| `bend` | градусы | сгиб посередине: локоть, колено |
| `axis` | градусы | направление сгиба (0 — вперёд-назад) |
| `x`, `y`, `z` | у `body` блоки, у остальных пиксели модели | смещение |

Знаки:

* рука/нога `pitch < 0` — вперёд-вверх (`-90` — рука вытянута вперёд, `-180` — вверх);
* правая `roll > 0` и левая `roll < 0` — наружу;
* сгиб руки `< 0` — локоть, сгиб ноги `> 0` — колено;
* `head.pitch > 0` — взгляд вниз; `torso.pitch > 0` — наклон вперёд;
* `body.pitch > 0` — отклониться назад, `body.roll > 0` — завалиться влево.

Ограничений на углы нет. Кость, которую анимация не задаёт, остаётся из нижнего слоя (движение или ваниль),
поэтому можно анимировать только руки, а ноги будут ходить сами.

## Формат `jn_anim`

```json
{
  "format": "jn_anim",
  "time": "ticks",
  "length": 20,
  "hold_last": true,
  "fade_in": "3t",
  "fade_out": "5t",
  "look": 1,
  "keys": [
    {"t": 0,  "pose": {"torso": [1, -1, 0], "rightArm": [-14, -4, 6, -12]}},
    {"t": 6,  "ease": "out", "pose": {"torso": [5, -7, -1], "rightArm": [-70, -26, 4, -62]}},
    {"t": 20, "pose": {"torso": [8, -10, -2], "rightArm": [-83, -31, 1, -78], "body.y": -0.05}}
  ],
  "tracks": {"head.yaw": [[0, 0], [12, 20, "smooth"]]}
}
```

* В `pose` кость задаётся массивом `[pitch, yaw, roll]` или `[pitch, yaw, roll, bend]`, объектом
  `{"pitch": -90, "bend": -20}` или одним каналом `"rightArm.bend": -20`.
* `tracks` — отдельные каналы со своими ключами: `[время, значение, кривая]`.
* Кривая ключа — переход **в** этот ключ: `smooth` (по умолчанию, плавно без остановки), `linear`, `step`,
  `ease` (замедление в обоих ключах), `in` (разгон к ключу), `out` (торможение в ключ). Названия вида
  `outquad`, `inoutsine` тоже понимаются.

| Поле | По умолчанию | Смысл |
|---|---|---|
| `time` | `ticks` | единицы времени: `ticks` (1/20 с), `seconds`, `frames` (с полем `fps`) |
| `length` | 20 | длина |
| `loop` | false | по кругу |
| `hold_last` | false | после конца держать последний кадр, пока не остановят |
| `speed` | 1 | скорость |
| `fade_in`, `fade_out` | 0.15, 0.2 | плавный вход/выход: число — секунды, `"6t"` — тики, `"120ms"`, `"3f"` — единицы файла |
| `ease` | `smooth` | кривая по умолчанию |
| `look` | 0 | насколько голова следит за взглядом игрока (1 — полностью) |
| `additive` | false | прибавляется к нижним слоям, а не заменяет их |
| `world_limbs` | false | повороты рук и головы заданы относительно тела, а не корпуса |
| `mask` | заданные кости = 1 | вес по костям: `{"leftLeg": 0, "torso": 0.5}` |
| `first_person` | нет | `{"mode": "model", "right_arm": true, "left_arm": false, "until": 10}` — руки модели видны от первого лица |

Старые файлы Player Animator (`player_animation/*.json`) читаются как есть: ключи соединяются плавными кривыми,
сгиб корпуса превращается в наклон от таза.

## Движение

Движение включается для игрока в повязке Годжо или во время движений мода (дэш, зарядка, полёт). Остальные
игроки двигаются как в ванили. Циклы лежат в `body_anims/loco_*.json` и `fly_*.json` (генерирует
`tools/anim-preview/gen_locomotion.py`), фаза шага идёт от пройденного пути, поэтому ноги не скользят.

| Скорость, блоков/с | Цикл |
|---|---|
| 0 | `loco_idle` |
| до ~4.6 | `loco_walk` |
| ~5.3–9 | `loco_run` |
| от ~9 | `loco_sprint` (сверхбег) |

В руках предмет, удар или натянут лук — эта рука берётся из ванили и крепится к нашему корпусу.

## Запуск из кода

```java
// на клиенте
BodyAnims.play(player, "red_cast");
BodyAnims.play(player, "red_cast", new Animator.Play().fadeIn(0.1).speed(1.2).mirror(true)
        .firstPerson(true, false, 0.5));
BodyAnims.stop(player, 0.3);
BodyAnims.isPlaying(player, "red_cast");

// с сервера (увидят все рядом и сам игрок)
BodyAnimNet.play(serverPlayer, "red_cast");
BodyAnimNet.stop(serverPlayer, 0.3);
```

Новая анимация на том же слое плавно сменяет текущую с того места, где та сейчас.

## Команды в игре (`/jnanim`)

| Команда | Что делает |
|---|---|
| `list` | все анимации и папка для своих |
| `play <имя> [скорость]`, `loop <имя>`, `mirror <имя>` | проиграть на себе (F5 — посмотреть со стороны) |
| `pose <имя> <тик>` | стоп-кадр в любой момент (можно дробный: `12.5`) |
| `step <±тики>` | сдвинуть стоп-кадр |
| `speed <x>` | замедлить/ускорить все анимации (0.1 — в 10 раз медленнее) |
| `stop` | плавно остановить |
| `info <имя>` | длина, петля, переходы, кости, откуда загружена |
| `reload`, `errors` | перечитать / показать ошибки загрузки |

## Превью без игры

`tools/anim-preview/run.sh` собирает тот же код движка и рисует модель игрока: GIF и лист кадров в
`tools/anim-preview/out`.

```bash
tools/anim-preview/run.sh clip red_cast     # любая анимация мода
tools/anim-preview/run.sh loco run          # движение: idle, walk, run, sprint, speeds, sneak, jump, charge, fly, dash
```

## Проверка в настоящей игре

Workflow `jujutsu-capture.yml` с `scenario = anim` запускает игру в CI: рядом появляется «актёр» в повязке
(`CaptureAnimScene`), стоит, идёт, бежит, приседает, прыгает, делает дэши, взлетает, летит, садится и показывает
техники, а камера снимает кадр каждые 2 тика. Кадры попадают в ветку `capture-results/<номер запуска>`.

## Инструменты Фиолетового (`tools/jnanim`)

`refmetrics.py` и `gen_max_purple_tracks.py` переводят замеры видео-референса в треки катсцены Максимального
Фиолетового (`MaxPurpleRefTracks.java`). Остальные скрипты там — от старой покадровой системы.
