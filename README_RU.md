# JUJUTSU NEON

[🇷🇺 Русская версия](README_RU.md) | [🇬🇧 English version](README_EN.md)

Мод для Minecraft Forge 1.20.1 с боевой системой и техниками в стиле Jujutsu.

## Что уже есть

- Повязка Годжо как активатор способностей.
- Шкала проклятой энергии и переназначаемые клавиши.
- Наземное и воздушное передвижение: дэши, заряжаемые прыжки, суперскорость и дальний телепорт.
- Blue и Maximum Blue.
- Red и Maximum Red.
- Hollow Purple с 5-секундной сценой каста, полётом на 160 блоков, круглым тоннелем аннигиляции и остаточными VFX.
- Нативные 4096×4096 VFX для Blue, Maximum Blue, Red, Maximum Red и Hollow Purple.
- Сгенерированное 48 kHz стерео-аудио.
- Minecraft 1.20.1 + Forge 47.x + Java 17.

## Сборка

Тяжёлые VFX и звуки генерируются во время сборки, поэтому репозиторий не хранит огромные готовые PNG/OGG-файлы.

```bash
python3 -m pip install pillow
python3 generate_resources.py
gradle build
```

GitHub Actions делает то же самое автоматически и загружает готовый JAR как артефакт.

## Управление

Стандартные бинды описаны в `JujutsuNeonMod.java`. Все основные клавиши можно переназначить через меню управления Minecraft.
